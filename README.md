# 🤖 AI-Powered RAG Chatbot

## Overview

This project is a Retrieval-Augmented Generation (RAG) chatbot that enables users to upload PDF documents and ask questions about their content. The system retrieves relevant information from the document and generates accurate, context-aware responses using a Large Language Model.

## Features

* PDF Upload and Processing
* Text Chunking and Embedding Generation
* ChromaDB Vector Database Integration
* Semantic Search and Retrieval
* AI-Powered Question Answering
* Interactive Streamlit User Interface

## Technologies Used

* Python
* Streamlit
* LangChain
* ChromaDB
* Ollama
* Sentence Transformers

## Workflow

1. Upload a PDF document.
2. Extract and split text into chunks.
3. Generate embeddings for each chunk.
4. Store embeddings in ChromaDB.
5. Retrieve relevant content based on user queries.
6. Generate context-aware responses using an LLM.

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
